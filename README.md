# 🎨 Griza

**Griza** es una aplicación móvil que permite a los usuarios **gestionar sus reservas en talleres creativos** de manera rápida, intuitiva y eficiente.  
Además, cuenta con una versión **admin** para la gestión de usuarios, clases y disponibilidad.

---

## 🚀 Características principales

- 📅 Reserva de clases en talleres creativos.  
- 👤 Gestión de perfil de usuario.  
- 🛠️ Panel de administración para organizar horarios y disponibilidad.  
- 📲 Aplicación instalable en dispositivos Android (APK).  
- ✅ Tests unitarios implementados para garantizar la calidad del software.  

---

## 🛠️ Tecnologías utilizadas

### 📱 Aplicación móvil (Cliente)
- [Kotlin](https://kotlinlang.org/)  
- [Android Studio](https://developer.android.com/studio)  
- [Jetpack Compose](https://developer.android.com/jetpack/compose)  
- [Dagger Hilt](https://developer.android.com/training/dependency-injection/hilt-android)  
- [Mockito](https://site.mockito.org/) (tests)  
- [Robolectric](http://robolectric.org/) (tests)  

### 🌐 API (Servidor)
- [Spring Boot](https://spring.io/projects/spring-boot) (Kotlin)  

---

## ⚙️ Instalación

### 📱 App de usuario
1. Descarga el archivo `.apk` desde la carpeta [Releases](../../releases).  
2. Instala el APK en tu dispositivo Android.  
3. Abre la aplicación y regístrate para comenzar a usarla.   

---

## 🚀 Uso

1. Crea una cuenta o inicia sesión.  
2. Explora los talleres disponibles.  
3. Reserva tu clase en el horario que prefieras.  
4. Visualiza y gestiona tus reservas en la sección de usuario.  

---

## 🧪 Tests

El proyecto cuenta con **tests unitarios** para garantizar la robustez de las funcionalidades principales:  

- 🔹 **JUnit**: framework principal de pruebas unitarias.  
- 🔹 **Robolectric**: para ejecutar pruebas de componentes Android sin necesidad de un emulador o dispositivo físico.
